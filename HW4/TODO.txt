Write a simple program using ProbLog. The goal of this assignment is to model and reason about uncertainties in a smart home fault diagnosis system. The idea is to 
(1) build a knowledge base that represents the probabilistic dependencies among various components of a smart home and 
(2) use it to diagnose likely faults when certain symptoms are observed.


Smart homes have many interconnected components (thermostats, lighting systems, motion sensors, door sensors, etc.). 
Each of these components can be in one of the two states - fail, not fail.  Therefore, each can be represented as a Boolean Variable.
Failures of some components may affect other components.  
However, due to sensor noise or incomplete observations, the system must reason probabilistically about the actual state of the world.
ProbLog allows encoding such uncertain knowledge using probabilistic facts and logical rules.
Consider a simplified smart home system with the following components:
•	Motion sensors in the living room and hallway: they report if motion detected or not
•	Light sensors:  they report if the light is on or off.
•	Temperature sensor:  Occasionally it may fail.
•	Thermostat: can fail to turn on the heating system.
•	Power supply: can occasionally be unstable.
You will encode a ProbLog model representing the relationships and failure probabilities between these components.
TASKS
Task 1. Model the Smart Home System in ProbLog:
o	Define probabilistic facts for component failures.  For example:
0.05::faulty_motion_sensor(living_room). 
0.05::faulty_motion_sensor(hallway).
0.02::faulty_light_sensor.
0.03::faulty_temp_sensor.
0.01::faulty_thermostat.
0.01::power_failure.
o	Define rules for deriving observations, such as:
motion_detected(Room) :- 
	not(faulty_motion_sensor(Room)), 
	movement(Room).

light_on :- 
	not(faulty_light_sensor), 
	light_switch_on.

heating_on :- 
	not(faulty_thermostat), 
	not(power_failure).
o	Encode possible causes for lack of heating, incorrect temperature readings, lights not turning on, etc.
Task 2: Define Queries
o	Given observations, query the probabilities of faults:
evidence(motion_detected(living_room), false).
evidence(light_on, false).
query(faulty_motion_sensor(living_room)).
query(power_failure).
query(faulty_light_sensor).
Task 3: Write a Report
o	Explain how your ProbLog program models the system.
o	Interpret the results of several queries with different sets of evidence.
o	Discuss how changing the prior probabilities affects inference.
